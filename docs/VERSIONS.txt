MedControl — история версий
==============================

1.2.2
- Отчёт по давлению — текстом, каждое измерение с новой строки
  (выровненные колонки), а не таблицей.
- Выбор количества точек на графике убран: всегда 60 точек на график,
  лишние точки разбиваются на следующие графики.
- Исправлено: подпись графика не печаталась дважды.

1.2.1
- Графики разбиваются на части: по 60 точек на один график (по умолчанию).
  Если точек больше — отчёт содержит несколько графиков, последний может
  быть неполным. Номер части и диапазон дат под каждым графиком.

1.2.0
- Отчёт в формате Word (.docx): таблицы данных + встроенные графики.
  Таблицы — книжная A4, графики — альбомная A4.
- Печать в два шага: «Что печатать?» → «Далее» → «За какой период?».
- Выбор «точек на графике» (0 — все): в окне печати и в настройках.
- Выбор дат появляется только в режиме «Выбрать даты…».
- Имена файлов отчётов больше не затирают друг друга.

1.1.8
- Окно печати: тип отчёта + печать графиков + период
  (день/неделя/месяц/год/свои даты с–по).
- «Графики» — пунктом списка; даты с–по внутри периода.
- Подсказка графика — по строке на линию; графики в PDF на одном
  альбомном листе.

1.1.7
- Ось графиков: без «-1» слева, метки не слипаются (автошаг целых чисел).

1.1.6
- Импорт лекарств из Excel (лист «Лекарства»: название, назначение, фото, инструкция).
- Вставка куска таблицы из буфера обмена.
- Печать графиков в PDF + периоды (день/неделя/месяц/год/даты).
- Зум графиков колесиком сохраняется при обновлении.
- Подсказки на всех кнопках; колокольчик активных напоминаний (красный при наличии).

1.1.5
- Диалоги файлов: владелец, стартовая папка, запоминание последней папки,
  запись в журнал (диагностика зависаний).

1.1.4
- Сверка базы с эталонным Excel (путь в настройках): что есть в файле
  и нет в базе + наоборот, прямо в программе.

1.1.3
- Дневник: блоки привязаны к порядку добавления тонометров (имена не важны);
  время без времени — 09:00, 10:00 и т.д. по дню.

1.1.2
- Импорт истории: гибкие форматы даты/времени, проверка диапазонов,
  счётчики «импортировано/пропущено», лимит 10 тонометров.
- Блочный дневник (слева Тонометр 1, справа Тонометр 2): импорт понимает
  оба формата; шаблон «Шаблон…» — в блочном виде с проверками Excel.

1.1.1
- Версия везде в коротком виде «X.Y.Z» (без четвёртого нуля).

1.0.10
- Замеры с одинаковым временем — на одной вертикали графика,
  каждый тонометр со своим значением; подсказка — по всем тонометрам момента.

1.0.9
- Новое окно ввода измерений: тонометры колонками (название + верхнее/нижнее/пульс),
  ручной ввод, общая оценка здоровья 1-10 и комментарии.
- После OK — окно проверки введённых данных («Сохранить» / «Исправить»).
- Старое окно сохранено; переключение: Настройки — «Ввод измерений».

1.0.8
- То же, что 1.0.7. Выпущена на GitHub для проверки автообновления.

1.0.7
- Обновление одной кнопкой: тихая установка без окон и автозапуск программы.
  (Только локальный установщик, на GitHub не выкладывалась.)

1.0.6
- Техническая версия для проверки обновления из приложения.

1.0.5
- Версия в заголовке главного окна («MedControl X.Y.Z»).
- Закачка обновлений с докачкой, повторами и прогрессом; при неудаче —
  предложение открыть страницу в браузере.

1.0.4
- Устойчивая проверка обновлений: до 3 попыток, таймаут 60 секунд.

1.0.3
- Исправлен адрес проверки обновлений (пропуск /repos/ давал 404).

1.0.2
- Техническая версия без изменений.

1.0.1
- Проверка обновлений с GitHub и установка новой версии из настроек.

1.0.0
- Первый выпуск: лекарства и напоминания, дневник давления/пульса,
  самочувствие 1-10, графики по тонометрам, Excel/PDF/печать,
  резервные копии, корзина, трей, синхронизация двух ПК, перенос базы.
