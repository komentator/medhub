# MedControl (MedHub)

Локальный менеджер приёма лекарств, дневник артериального давления/пульса и самочувствия
для Windows 11 x64. Все данные хранятся только на компьютере пользователя —
без облака, интернета, телеметрии и скрытых процессов.

## Возможности

- **Напоминания** — собственное окно поверх остальных (крестик не закрывает),
  группировка событий в пределах 15 минут, «Отложить 15 минут» с повтором,
  снижение системной громкости на время напоминания с восстановлением.
- **Лекарства** — ежедневно или по дням недели, своя дозировка на каждое время,
  фото упаковки/таблетки/инструкции, печатные инструкции, массовый ввод,
  внеплановый приём, история со snapshot (старые записи не меняются).
- **Давление и пульс** — до 10 тонометров, графики по каждому тонометру
  с легендой (зум колесиком, подсказки со значениями), статистика периода,
  импорт/экспорт Excel без дублей, печать и PDF-отчёты.
- **Самочувствие** — шкала 1–10, автосвязь с приёмами и измерениями (±15 мин).
- **Синхронизация двух ПК** в одной сети (LAN/Wi-Fi одного роутера):
  «Принял»/«Отложить» на любом компьютере. Плюс перенос базы одним файлом
  `.mcpack` (в т.ч. по сети из мастера первого запуска).
- **Надёжность** — транзакции SQLite, корзины с восстановлением, ежедневные
  и ручные резервные копии, автовосстановление из последней целой копии,
  технический журнал, единственный экземпляр, автозапуск свернутым в трей.

Подробности — в [инструкции пользователя](docs/USER_GUIDE.md).

## Установка

Нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
Готовый установщик собирается из `installer/innosetup.iss` (Inno Setup 6):

```text
installer\output\MedControl_Setup_1.0.0.exe
```

При удалении программы установщик спрашивает, удалять ли данные.

## Сборка из исходников

```text
dotnet restore
dotnet build -c Release
dotnet test
```

Публикация для установщика:

```text
dotnet publish src/MedControl -c Release -r win-x64 --self-contained false
```

Требования: .NET 8 SDK, Windows 10/11 x64.

## Версии и обновления

Каждое изменение выходит под новой версией (`<Version>` в `MedControl.csproj`
+ `MyAppVersion` в `installer/innosetup.iss`). Кнопка «Проверить обновления»
в настройках смотрит последний Release на GitHub и предлагает скачать setup.

Как выпустить версию `X.Y.Z`:
1. Поднять версии, собрать, прогнать тесты, опубликовать, собрать установщик.
2. Закоммитить, запушить, поставить тег: `git tag vX.Y.Z && git push origin vX.Y.Z`.
3. На GitHub создать **Release** `vX.Y.Z` и прикрепить
   `installer/output/MedControl_Setup_X.Y.Z.exe`.

## Технологии

C# · .NET 8 LTS · WPF (MVVM) · SQLite (Microsoft.Data.Sqlite) · NAudio ·
ClosedXML · LiveCharts2 · PdfSharp · xUnit. Только x64, MSIX-ready.

## Структура

```text
src/MedControl
├── Models | Data | Repositories      # сущности, SQLite, миграции, доступ к данным
├── Services | Scheduling | Audio     # напоминания, планировщик, звук/громкость
├── Backup | Reports | ImportExport   # копии, PDF/печать, Excel
├── Sync                             # синхронизация ПК-ПК + перенос .mcpack
├── ViewModels | Views                # MVVM, окна (пошаговый ввод, визарды)
├── Logging | Settings | Localization # журнал, настройки, ресурсы
└── Resources                         # иконка приложения
tests/MedControl.Tests                # 50+ тестов критической логики
```

Плановые события — виртуальные (генерируются из расписания),
факты хранятся со snapshot и не зависят от будущих правок.

## Данные

- БД: `%LOCALAPPDATA%\MedControl\Data\medcontrol.db` (WAL, транзакции, миграции)
- Копии: `%LOCALAPPDATA%\MedControl\Backups\` (авто — последние 7, ручные — бессрочно)
- Отчёты: `%LOCALAPPDATA%\MedControl\Reports\medkontrol_*.pdf`
- Фото: `%LOCALAPPDATA%\MedControl\Photos\`

## Приватность

Вся медицина — только локально. Нет сети (кроме LAN-синхронизации по вашему
желанию), рекламы, аналитики и автозапуска без спроса.
